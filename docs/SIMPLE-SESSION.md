# Trailk 1.1.0 · простой интерфейс, локальная установка

Установлено: `~/Applications/Trailk.app`, версия 1.1.0, сборка 2.
Предыдущая версия сохранена целиком в `calm-macos/backups/Calm Translate 1.0.app.saved`. Идентификаторы приложения, папка данных и Keychain сохранены; существующий Keychain-helper скопирован без изменения байтов. GitHub не обновлялся.

## Как пользоваться

1. Откройте Zoom и Trailk. Нажмите **Начать**. Один экран объяснит, какой звук отправляется OpenAI, длительность и стоимость. Разрешите именно этот разговор. Для перевода вашей мысли отметьте отдельный пункт; контекст последних трёх строк — по желанию.
2. При первом запуске Mac может отдельно попросить доступ к системному звуку для **Trailk · звук Zoom**. Это собственное разрешение нового приложения. Микрофон и экран не нужны. Во время разговора ничего переключать не требуется; паузы продолжаются автоматически. Текущий текст находится отдельно от устойчивой истории. Прокрутите вверх, чтобы читать в своём темпе; **К новым строкам** возвращает следование. Размер текста регулируется ползунком.
3. Введите свою мысль по-русски и нажмите **На английский**. Текст предназначен для чтения вслух и редактирования. **Другие формулировки** предлагает варианты только вашей введённой мысли; выбор вручную. Отправки в Zoom и озвучивания нет. **Остановить** завершает сессию; историю оставляет в окне.

Пример без звука/API находится в **Настройки и проверка → Источник**. Он показывает искусственные строки, а не качество перевода. Настройки чтения, выбранная длительность и предпочтение контекста сохраняются; текст разговора и мысли не сохраняются между окнами.

## Что изменено

Одна видимая кнопка управления сессией, без отдельного Start в helper и без «Я говорю». В реальном режиме после готовности WebSocket native helper автоматически начинает только заранее подтверждённый Zoom output. Автоматическая индикация «есть звук/пауза» использует уровень PCM; это не распознавание личности говорящего и не подтверждение качества VAD. Аудио с паузами передаётся непрерывно, сегментация перевода происходит у провайдера. Свой микрофон не захватывается, собственная устная русская речь не переводится: сейчас предусмотрена введённая мысль. Отдельный режим микрофона потребует отдельной реализации и явного разрешения.

Согласия новой сессии живут только в RAM, ограничены источником/временем/бюджетом и не создают credential. Ранее установленный STOP не удаляется: только явное подтверждение «Разрешаю возобновить…» в этом окне разрешает одну текущую сессию. На диске записывается только отдельный резерв этой явно подтверждённой попытки и диагностические метаданные; прежние approval/budget файлы не изменяются. Отмена окна не даёт согласия. Повторные быстрые клики подавляются. Любой новый платный старт после Stop/ошибки требует нового подтверждения; автопереподключения, автоматической повторной отправки и сброса резерва нет.

Для текстовых запросов отдельный резерв $0.50 ограничивает 10 попыток по $0.05 резерва. Контекст разрешается отдельно на сессию, затем его предпочтение действует без переключений на каждую реплику. Запрос только по нажатию. Отмена прекращает ожидание/показ результата, но не может отменить уже отправленный провайдеру запрос и не возвращает резерв автоматически. Остановленная/истёкшая сессия не даёт нового текстового доступа.

## Что проверено

45 Python-тестов, 8 JS-тестов, Swift compilation/typecheck, встроенный frozen runtime/TLS/WebSocket/assets и строгая ad-hoc подпись. 22 проверки настоящего AppKit/WKWebView окна: единая кнопка, накопление, неподвижность прочитанного текста, размер/позиция, сохранение настроек, ручной выбор английского, закрытие, ручное восстановление локального сервера, отмена ответа, отдельное согласие/отмена/отсутствие переноса согласия. Синтетические 90 минут PCM и WebSocket, пауза → звук, повторные клики, ошибка handshake, обрыв соединения и отмена не обращались к OpenAI и не читали ключ. Автоматический тест не нажимал «Разрешить и начать».

## Оставшиеся ограничения реального теста

Захват Zoom, фактическая изоляция от других приложений/микрофона, отражённый собственный голос, смена AirPods/выходного устройства, системный отказ, качество/задержка перевода и реальная продолжительность соединения провайдера ещё не проверены. Zoom output смешивает участников; диаризация не заявляется. Клиентский максимум 90 минут не гарантирует поддержку такой длительности провайдером. При отсутствии native input после готовности API — остановка через 20 секунд; при потере источника/устройства/буферов/heartbeat/переполнении — остановка. Ранний отказ также сохраняет резерв; это не означает фактическое списание.

[OpenAI model pricing](https://developers.openai.com/api/docs/models/gpt-realtime-translate): $0.034 за минуту аудио, включая передаваемые паузы, проверено 3 октября. Экран добавляет 10% к расчётной стоимости как предел резерва: для 30 минут $1.13 аудио + опционально $0.50 текста. Фактический биллинг неизвестен; отсутствие оплаты за остановленный запрос не обещается. Используется специальный `/v1/realtime/translations`, не обычный chat proxy. Production PATAS/OmniRoute, ключи, маршруты и настройки не менялись.

Для отката завершите Trailk, перенесите его из Applications и верните каталог `.app.saved` под прежним именем `Calm Translate.app`. Папку данных и Keychain удалять не нужно.
