All four returned groups passed whole-JSON, terminal, syntactic neutrality and numeric freshness guards. These guards did **not** guarantee relevance. First leads were “When should we leave?”, “Tomorrow?”, “When are we leaving?” and “Which amount is correct?”. This is a semantic failure rather than a technical transport error.
